# Security

The checker reads local files and runs offline. Use an authorized checkout and keep credentials, private system details and personal data out of records and evidence notes. GitHub Actions uses read-only contents access and does not persist checkout credentials.

Report a vulnerability privately through the repository's **Security** tab when private vulnerability reporting is available. Use a small synthetic reproduction and include the affected version, platform, command and observed result. Please keep credentials and live-system data out of reports. The maintainer can coordinate disclosure after receiving the report.

Architecture Decision Library

A commit shows what changed. An architecture decision record gives you a place to preserve why.

This library keeps decisions in Markdown with their context, alternatives, trade-offs, and verification evidence. An example follows a search implementation from whole-file validation to a streaming replacement, preserving the reasoning for both choices.

A dependency-free Python checker catches duplicate IDs, invalid statuses, broken local links, and stale indexes. A reviewer can follow the evidence back to the implementation.

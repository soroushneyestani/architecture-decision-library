# Architecture Decision Library 0.1.0

Version 0.1.0 provides a versioned Markdown decision library and a dependency-free Python checker. Six records document five accepted decisions and one replaced decision. Their confirmation sections and evidence notes connect the design to implementation and verification.

Start with the [decision index](../adr/README.md), [template](../adr/TEMPLATE.md) and [format contract](../SPEC.md). Use Python 3.13 and run `python -X utf8 -B scripts/check_adrs.py` from the extracted source. Use `pwsh -NoProfile -File scripts/verify.ps1` to run the contract tests as well.

The source ZIP contains the reviewed workflow, checker, tests, Markdown library and documentation. Verify it with the accompanying SHA-256 manifest. Version 0.1.0 documents the initial format contract. Future versions may change it. [Verification evidence](../RELEASE_EVIDENCE.md) · [MIT license](../../LICENSE) · [Third-party notices](../../THIRD_PARTY_NOTICES.md)

The checker supports the library's documented Markdown conventions. Reviewers check evidence quality, external destinations and heading fragments. The archive records no production adoption or performance guarantees.
